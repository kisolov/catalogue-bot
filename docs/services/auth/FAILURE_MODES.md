# auth — отказы

Единственная исходящая зависимость — Redis ([`RedisTokenRepository`](../../../src/auth/redis_adapter.py),
таймаут подключения `REDIS_TIMEOUT`, по умолчанию 30 с).

| Момент | Отказ Redis | Что происходит |
|---|---|---|
| Вход (`create_token` → `SET`) | недоступен | исключение клиента → 500; токен не выдан, но пользователь мог быть создан |
| Проверка токена (`GET`) | недоступен | 500 на любом защищённом запросе; токен не принимается «на слово», чтобы не пропустить отозванный |
| Выход (`DEL`) | недоступен | 500; токен остаётся действительным до TTL |
| Потеря данных Redis (рестарт без persistence) | ключи исчезли | все токены становятся недействительными → 401, нужен новый вход |

Ретраев, кэша и деградации нет — осознанно (см. [общий файл](../FAILURE_MODES.md)).
