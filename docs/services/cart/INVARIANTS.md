# cart — инварианты

| Правило | Где обеспечено |
|---|---|
| Одна позиция на пару (пользователь, товар); повторное добавление **увеличивает** `quantity` | [`PonyCartItem`](../../../src/shared/orm/models.py) `composite_key`, [`add_item`](../../../src/cart/adapters/pony.py) |
| `user_id` берётся из токена, а не из тела запроса: чужую корзину изменить нельзя | [`endpoints/cart.py`](../../../src/bootstrap/endpoints/cart.py) |
| Корзина не проверяет `is_active` и остаток при добавлении — они проверяются в момент заказа | [`create_from_cart`](../../../src/orders/adapters/pony.py) |
| `quantity` от 1 до 1000 | `CHECK` в [`db.sql`](../../../migrations/sql/db.sql) |
| Оформление заказа очищает корзину в той же транзакции | [orders](../orders/INVARIANTS.md) |
| Удаление позиции: 404, если её нет | [`remove_item`](../../../src/cart/adapters/pony.py) |

## Как есть (известные ограничения)

Проверено запуском, код не менялся.

| Запрос | Результат | Замечание |
|---|---|---|
| POST с `quantity` 0, −1 или 1001 | 409 «Нарушение уникальности CartItem[…]» | отказ верный (CHECK), сообщение вводит в заблуждение; в схеме запроса границ нет |
| Прибавка к существующей позиции сверх 1000 | не проверялось | CHECK сработает при коммите |

Тесты: [`test_cart.py`](../../../tests/cases/groups/test_cart.py).
