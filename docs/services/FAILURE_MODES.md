# Поведение при отказах

| Зависимость | Отказ | Что происходит |
|---|---|---|
| Redis | недоступен при входе | `create_token` падает → 500, токен не выдан |
| Redis | недоступен при проверке токена | любой защищённый запрос → 500 (токены не проверяются «мягко», чтобы не пропустить отозванный) |
| PostgreSQL | недоступен при старте | приложение не стартует, контейнер перезапускается, `depends_on: service_healthy` ждёт БД |
| PostgreSQL | ошибка внутри заказа | вся транзакция откатывается: остатки, корзина и заказ не меняются |
| Настройки | нет `DB_*`, `JWT_SECRET_KEY`, `TELEGRAM_BOT_TOKEN` | [`main.py`](../../main.py) падает при старте с `ValidationError`, а не на первом запросе |
